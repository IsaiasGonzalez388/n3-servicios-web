# N3 Servicios Integrales — Sitio web

Sitio estático (HTML + CSS + JS), sin base de datos ni dependencias.

## Páginas
- `index.html` Inicio
- `nosotros.html` Quiénes somos
- `servicios.html` Áreas de servicio en detalle
- `como-trabajamos.html` Modalidad de trabajo
- `cobertura.html` Provincias
- `contacto.html` Formulario (Netlify Forms) + WhatsApp
- `gracias.html` / `404.html`

## Antes de publicar (completar)
Buscar `[COMPLETAR]` y `5493810000000` y reemplazar por los datos reales
(teléfono, e-mail, domicilio y número de WhatsApp con código de país, sin +).

## Ver en tu computadora
Abrir `index.html` con el navegador (doble clic).

## Publicar en Netlify
1. netlify.com → "Add new site" → "Import an existing project" → GitHub → elegir este repo.
2. Build command: vacío. Publish directory: `.`
3. Los envíos del formulario aparecen en Netlify → Forms (se puede activar aviso por e-mail).

## Publicar en Cloudflare Pages / GitHub Pages
Funciona igual: sin build, carpeta raíz del repo.
